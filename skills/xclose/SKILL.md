# xClose

Follow [shared behaviors](../../STANDARDS/rules/shared-behaviors.md).

Review the agreed scope, saved work, verification, requested delivery, and any running work that depends on this session. Reuse existing evidence; check only what is missing or may have changed.

Finish already-authorized loose ends. Preserve essential continuation context in existing project records when needed. Closing alone does not authorize committing, pushing, deploying, discarding work, or archiving the chat.

Say whether it is safe to close and briefly name anything unfinished and where to resume. Distinguish safely pausing from completing the task. Stop without starting another work cycle.
